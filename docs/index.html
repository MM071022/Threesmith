Threesmith

three.js ships a release almost every month and removes old APIs. Agents write the old ones. Threesmith checks their code against the three version your project has installed.

Install in VS Code Install in Cursor Claude Code plugin GitHub 
claude mcp add threesmith -- npx -y threesmith mcp
npx threesmith review        # scored review
npx threesmith api Mesh      # exact API of your version
npx threesmith check .       # open the page headless
API lookupRead from node_modules/three: signatures, deprecations, import paths. Typos get "did you mean".
Scored review39 rules. Removed APIs, wrong imports, black scenes, shadows that never draw, per-frame allocations, missing dispose.
Headless checkChromium with software WebGL 2: console errors, no canvas, lost context, blank frames, screenshot, baselines.
CI receiptA GitHub Action that posts the review and the visual check on every pull request.

Works with

Claude Code (plugin with hooks), Claude Desktop (.mcpb), Codex, Cursor, Cline, Gemini CLI, or any MCP client. See llms-install.md.

Honest limits

  • WebGL 2 is reliable in CI; WebGPU is best effort.
  • The review reads text, not types. It can be wrong: report it.
  • No benchmark results are published yet.
