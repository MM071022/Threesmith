3D models for three.js, from code

three_model_build makes a clean, deterministic .glb from a ready-made kind or a JSON spec: a node per part, UVs and normals, names as GLTFLoader shows them, +Y up, metres, front +Z. Each render below is three.js itself, headless, loading the built file with GLTFLoader. The numbers are the builder's own summary.

npx threesmith model build car -o public/models/car.glb
npx threesmith model view public/models/car.glb      # front, side and top views as text
npx threesmith model lint public/models/car.glb --archetype car
