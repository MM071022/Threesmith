Install Threesmith

It runs locally over stdio with npx: nothing to clone or build, no API key. Run your agent from the project folder, or pass --project <path>.

Claude Code: the plugin (recommended)

The MCP server plus hooks (each edited three.js file is reviewed, broken asset paths named, errors in command output explained), 8 skills and 2 subagents.

/plugin marketplace add laaielichter/Threesmith
/plugin install threesmith@threesmith

MCP server only: claude mcp add threesmith -- npx -y threesmith mcp. Hooks off: THREESMITH_HOOKS=0.

Claude Desktop

Download threesmith.mcpb from the latest release and open it, then pick your project folder in the settings. Or build it: npm run build:mcpb.

Cline, Windsurf, Zed and any MCP client

Options

OptionEnvironmentWhat it does
--tier cheap | premiumTHREESMITH_TIERcheap (default): short, capped output and numbered steps for small models; premium: full detail
--tools core,runTHREESMITH_TOOLSload only these sets (core, run, live, build, model, all) or single tools
--read-onlyTHREESMITH_READ_ONLY=1leave out tools that always write, refuse write options; dry runs still work
--project <dir>THREESMITH_PROJECTthe folder tools use when no path is given
—THREESMITH_PROTECTfolders no write may touch (also "protect" in threesmith.json)
—THREESMITH_LEARN=0no local learning (false-alarm feedback)

Browser tools

three_check, three_inspect, three_play, three_perf, three_leaks, three_session and three_build need playwright-core and a Chromium:

npm i -D playwright-core
npx playwright-core install chromium
npx threesmith doctor --env     # what is missing

Or set THREESMITH_CHROMIUM to a Chromium binary. Everything else works without a browser.
